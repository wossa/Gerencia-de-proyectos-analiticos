Criterio de priorización

Por defecto: alto ≥ 30%, medio ≥ 15% y bajo < 15%. Los umbrales pueden ajustarse para simular políticas de intervención.

Lectura del modelo

La probabilidad es la salida del modelo SAT-DU y funciona como señal de priorización, no como una decisión automática. Debe complementarse con revisión académica, financiera y de bienestar antes de tomar decisiones sobre un estudiante.

Calidad y ética

La base es sintética y no contiene datos personales reales. En un escenario productivo se deben aplicar controles de acceso, trazabilidad, minimización de datos y monitoreo de sesgos.

Project Charter — Resumen

Objetivo
Sistema de alerta temprana para estudiantes de 1.º y 2.º semestre.
Modelo
Probabilidad individual de deserción y priorización por nivel de riesgo.
Criterio analítico
AUC ≥ 0,69 y evaluación de capacidad de focalización.
Producto
Modelo + API de predicción + tablero SAT-DU + transferencia a usuarios.
