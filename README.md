# SAT-DU v3 — GitHub Pages autocontenido

Esta versión contiene la base sintética SAT-DU embebida dentro de `index.html`.

## Despliegue
1. En el repositorio `Gerencia-de-proyectos-analiticos`, reemplace el `index.html` actual por este archivo.
2. Haga Commit sobre `main`.
3. No cambie Settings > Pages.
4. Espere unos minutos y recargue el sitio.

No es necesario subir `base_sintetica_sat_du.csv` para que aparezcan los datos.
El tablero sigue permitiendo cargar manualmente archivos .xlsx, .xls o .csv.

La base incluida tiene 1.800 registros.
